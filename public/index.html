          How it works

          1. Evidence, no AI. The server loads the homepage and lists every third-party script, pixel and iframe, matched against a list of known trackers.
          2. Researcher. An open-weight model finds and reads the privacy policy with Otari's web search and web fetch, and lists its concrete promises.
          3. Analyst + Judge. A second model counts trackers by running Python in Otari's code sandbox; a third judges each promise against the evidence, behind a prompt-injection guardrail.
          4. Report. A writer model turns the verdicts into plain language. Every person gets their own daily budget on Otari, so one heavy user can't drain the app.
